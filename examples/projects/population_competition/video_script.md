# Video Script: Population Competition

1. Open `fisiCs/examples/projects/population_competition` in the IDE.
2. Show the small model files and the project manifest.
3. Run `make examples-project NAME=population_competition`.
4. Point out the deterministic tick table and nonnegative state.
5. Ask an agent to change one behavior rule, such as resource recovery.
6. Rerun the project target to show the expected-output oracle.
7. Generate artifacts with `make examples-project-artifacts NAME=population_competition`.
